# ADR 0001：P0 边界

采用模块化单体、API/Worker 共享代码与镜像。Agent 是图职责节点，非单独微服务。

- 队列可能至少一次投递；PostgreSQL 是业务事实来源，outbox 为投递依据；并发消费用数据库行锁串行化。
- LangGraph checkpoint 与业务事务分开；P0 节点只有确定性纯计算，无外部副作用。检查点先成功、业务事务失败时重跑是安全的，真实退款工具必须在 P2 增加 action_id 幂等和审批。
- P0 通过单演示 token 保护本机 API，不等价于用户鉴权，生产环境启动拒绝。完整用户和客服角色后续实现。
- 嵌入 Beat 的单 Worker 简化入门部署；扩容前将 Beat 单独运行，再评估任务队列与锁策略。
- Langfuse 和真实模型在首次模型调用阶段接入；P0 仅用结构化应用日志和数据库检查点，不虚构外部 Trace。
- 云自动部署脚本在 P4 实施，P0 仅准备镜像发布及 digest 清单；避免默认开放尚不具备多用户权限的演示。
